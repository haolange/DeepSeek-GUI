本模块为纯资源目录，不包含可执行代码，按工具划分为两个子树：
- `officecli/`：通过 `manifest.json`（schemaVersion 1）声明 officecli 各平台（darwin-arm64/darwin-x64/linux-x64/win32-x64）的下载地址、SHA256、文件大小及 releaseTag，配合 `legal/` 下的 LICENSE、NOTICE、THIRD-PARTY-NOTICES.txt 满足开源合规要求。
- `whisper/`：按平台子目录（darwin-arm64、linux-arm64、linux-x64、win32-x64）存放 whisper.cpp v1.9.1 的运行时依赖，其中 linux-arm64 直接内嵌 `libggml*`、`libparakeet.so`、`libwhisper.so` 等共享库与 `whisper-cli` 可执行文件；其他平台仅保留 `runner.json` 由运行时从 GitHub Releases 拉取对应压缩包；每个平台目录均提供 `runner.json` 描述 runner 名称、source URL、sourceSha256、ref、platform、arch 等信息，供主程序解析后下载并校验。
依赖方向单向：主程序读取本模块清单以决定下载源与校验值，本模块不反向依赖任何源码。

构建命令 `npm run build` 会先清理输出、执行 `tsc -p tsconfig.build.json`，再运行 `scripts/write-runtime-build-manifest.mjs` 生成运行时构建清单；测试入口为 `node ./scripts/run-tests.mjs`，并在每次测试前执行 `runtime-build-manifest.test.mjs` 验证清单一致性；内存回归测试通过 `npm run test:memory-growth` 运行；Agent 重放基准通过 `npm run benchmark:replay -- --suite benchmarks/agent-core.json` 驱动；CLI 可执行文件为 `dist/cli/serve-entry.js`，安装后提供 `kun` 和 `kun-dv` 两个 bin。

脚本按职责分层组织：
- 入口编排层：`release.sh` 仅转发到 `release-mac.sh`；`release-mac.sh` 负责 macOS 构建、smoke 测试、创建 GitHub draft release 并上传 dmg/zip/evidence；`release-win.sh` 复用同一 tag 在 Windows 上构建 exe 并追加上传，最终通过 `--r2-promote --publish` 联合发布。
- 共享库层：`lib/release-common.sh` 集中版本计算、通道归一化、签名环境变量注入、并发锁、清理、release notes 生成等通用逻辑；`lib/extension-release-execution.mjs` 封装 npm/子进程调用、API 兼容性断言与可发布依赖检查。
- 产物组装层：`pack-bundled-extensions.mjs` 将示例扩展打包为 `.kunx` 并生成确定性目录与 `catalog.json`；`assemble-tui-release.mjs` 从多目标 TUI 归档中抽取内嵌 `kun/release.json` 并产出 `release-tui.json` 与 `SHA256SUMS-tui.txt`。
- 发布层：`publish-r2.mjs` 基于 `@aws-sdk/client-s3` 将 GUI 平台产物与 TUI 产物上传至 Cloudflare R2，并按 channel (`frontier`/`stable`) 生成 `latest.json` / `latest-tui.json` 指针，支持 `upload`、`upload-tui`、`promote` 三种命令。
- 校验与 smoke 层：大量 `check-*`、`verify-*`、`smoke-*` 脚本分别验证扩展文档、外部项目、包体积、运行时依赖、macOS 原生架构、Windows 签名、打包产物一致性等，并以 `.test.*` 配对文件提供单元测试。
- 辅助工具：`after-pack.cjs`、`before-pack.cjs`、`vite-development-renderer.config.mjs` 等作为 electron-builder/Vite 钩子；`ensure-*`、`prepare-*` 脚本处理本地环境依赖。
依赖方向自下而上：smoke/check → 产物组装 → 平台发布 → R2 推送，所有脚本通过 `ROOT` 变量回退到仓库根，避免硬编码路径。

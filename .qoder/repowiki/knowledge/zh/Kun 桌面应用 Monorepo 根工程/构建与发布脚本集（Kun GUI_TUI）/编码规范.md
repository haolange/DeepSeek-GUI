- 每个脚本通过 `ROOT="$(cd "$(dirname "$0")/.." && pwd)"` 定位仓库根，再以相对路径引用其他脚本与资源，避免绝对路径依赖。
- Bash 脚本统一使用 `set -euo pipefail` 并在错误时调用 `die` 输出红色错误信息后退出。
- 参数解析采用 `while [[ $# -gt 0 ]]; do case "$1" in ... esac; done` 模式，未知 flag 直接报错退出。
- Node 脚本同时暴露可导入函数与 CLI 入口，通过 `if (process.argv[1] && resolve(process.argv[1]) === fileURLToPath(import.meta.url))` 判断是否直接执行。
- 对外部命令执行统一通过 `runRequiredCommand` / `spawnSync` 包装，失败时抛出包含 stdout/stderr 的 Error，便于测试捕获。
- 校验类脚本成对出现：主脚本与同名 `.test.*` 文件，使用相同命名约定组织单元测试。
- R2 上传与 promote 流程通过 `RELEASE_CHANNEL`/`--channel`/`--stable`/`--frontier` 归一到 `frontier` 或 `stable` 两个通道，禁止任意字符串。
- 产物名称与元数据严格遵循固定命名约定（如 `Kun-*-mac-arm64.dmg`、`Kun-TUI-${version}-*`），并通过正则或白名单校验后再写入文件系统。

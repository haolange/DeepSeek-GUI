运行前需安装 Node ≥ 22、npm、GitHub CLI 并通过 `gh auth login`；macOS 构建需在 macOS 上执行，Windows 构建需在 Windows/Git Bash 上执行；可通过 `scripts/release.local.env` 或 `release.local.env` 注入 R2/GitHub/签名凭据；macOS 构建后必须用相同 tag 在 Windows 执行 `release-win.sh --tag vX.Y.Z --r2 --r2-promote --publish` 完成三端联合发布；TUI 发布需先运行 `assemble-tui-release.mjs` 生成 `release-tui.json`。

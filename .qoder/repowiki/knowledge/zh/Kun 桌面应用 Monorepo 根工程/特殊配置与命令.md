`npm run dev` 会依次执行 `build:extensions` → `build:kun` → `build:bundled-extensions` → `electron-vite dev`，并以 development flavor 启动；`npm run build` 走完整构建并追加 `check:packaged-runtime-deps`；`npm run dist:mac|win|linux` 触发对应平台的 electron-builder 打包与体积检查；`npm run release:mac|win` 调用 `scripts/release-mac.sh` / `release-win.ps1` 完成签名与发布；`npm run test` 同时运行扩展子包测试与根级 Vitest。

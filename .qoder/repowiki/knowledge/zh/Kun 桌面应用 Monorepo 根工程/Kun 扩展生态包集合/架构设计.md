本模块以 npm 包形式组织，按职责拆分为五个独立发布包，依赖方向自底向上：
- `@kun/extension-api`（基础层）：定义框架中立的扩展契约，导出 accounts、agent、artifacts、client、common、composer-context、compatibility、content-scripts、errors、lifecycle、jobs、manifest、media、methods、permissions、providers、registry、services、tools 等模块；通过 Zod schema 校验所有消息类型，并额外暴露 `schema/kun-extension.schema.json` 作为 manifest 校验文件。
- `@kun/extension-react`（UI 适配层）：基于 React 为 Webview 提供官方绑定，仅依赖 `@kun/extension-api`，将 React 声明为 peerDependency 以保持框架中立。
- `@kun/extension-test`（测试层）：实现 `FakeHostTransport`、`FakeStorageService`、`FakeWorkspaceService`、`FakeAgentService`、`FakeJobService`、`FakeMediaService`、`FakeClock` 等确定性测试夹具，全部通过 `transport.handle(...)` 注册方法处理器来模拟宿主行为，供扩展作者编写无网络、可重放的单元测试。
- `create-kun-extension`（CLI/脚手架）：通过 `bin.create-kun-extension` 暴露命令行入口 `src/cli.mjs`，并以 `src/scaffold.mjs` + `templates/` 模板生成新扩展项目，同时复用 `@kun/extension-api` 的类型。
- `@kun/provider-catalog`（数据层）：独立的模型 Provider 连接目录，Node ≥22.19 要求，与其他包解耦。
各包统一使用 ESM (`"type": "module"`)、`tsconfig.build.json` 编译到 `dist/`、Vitest 运行测试，并通过 `exports` 字段精确控制入口。

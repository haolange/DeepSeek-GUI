- 每个扩展在 `src/host/extension.ts` 中导出 `activate(context)` / `deactivate()`，并通过 `context.subscriptions.add(...)` 注册命令、工具或 Provider，由 Kun 负责生命周期回收。
- Webview 入口通过 `declare global { interface Window { readonly kunExtension: HostTransport } }` 注入类型，并使用 `new ExtensionHostClient(window.kunExtension)` 发起 RPC 与 UI 状态同步。
- 复杂扩展使用 `kun-extension.json` 集中声明 `commands`、`views.rightSidebar`、`tools`、`agentProfiles`、`settings`、`activationEvents` 与 `permissions`，并在 `main`/`browser` 指向 Vite 输出产物。
- 工具定义在 manifest 中以 `inputSchema`/`outputSchema` 严格约束参数，并标注 `sideEffects`（read/write/external/destructive）、`idempotent`、`maxOutputBytes` 等安全边界字段。
- Vite 构建拆分为 host 与 webview 两套 tsconfig（如 `tsconfig.host.json`、`tsconfig.webview.json`），并通过独立 `vite.host.config.ts` 与默认 `vite.config.ts` 分别处理 Node 与浏览器目标。
- 测试统一使用 Vitest，并以 `<module>.test.ts(x)` 命名并与被测文件同目录放置，fixture 数据放在 `fixtures/` 并通过 `generate-local-fixture` 脚本生成/校验。

本模块按功能划分为两个并列子树：`extensions/` 下每个目录是一个独立的 npm 包（私有 `@kun-examples/*`），通过各自的 `package.json` + `vite.config.ts` + `tsconfig.*.json` 分别构建 Host 端（Node）与 Webview 端；`ui-plugins/starlight/` 是纯声明式 UI 插件，仅由 `manifest.json` 描述形象、背景、标签与 token。所有扩展统一依赖 `@kun/extension-api`，不直接引入 Kun 运行时或 Electron，Host 入口暴露 `activate/deactivate` 并通过 `context.commands/registerCommand`、`context.tools.registerTool`、`context.modelProviders.registerProvider` 注册能力；Webview 通过全局 `window.kunExtension` 上的 `HostTransport` 使用 `ExtensionHostClient` 与 Host 通信。`kun-video-editor` 作为参考实现，内部再分 `engine/`（领域逻辑）、`host/`（工具与服务桥接）、`webview/`（React 视图）三层，并通过 `kun-extension.json` 集中声明命令、视图、Agent Profile、Tools、Settings、激活事件与权限。根级脚本 `run-repository-kun-cli.mjs`、`validate-manifest.mjs`、`copy-static-assets.mjs` 为仓库内联验证与打包辅助，确保示例构建不依赖外部 `PATH` 上的 kun CLI。
